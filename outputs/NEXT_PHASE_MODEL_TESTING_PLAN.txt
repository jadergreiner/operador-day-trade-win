## Integration Test (10 min)

```python
# Test full inference pipeline
python -c "
import pickle
import json
import numpy as np

# Load model
with open('data/models/xgboost_v1.0.pkl', 'rb') as f:
    model = pickle.load(f)

# Load features
with open('data/feature_names.json', 'r') as f:
    feature_names = json.load(f)

print(f'Model features expected: {len(feature_names)}')

# Simulate trading signal generation
print('Simulating 10 market signals...')
for i in range(10):
    # Generate random 24-feature vector
    X = np.random.randn(1, 24)

    # Get prediction
    pred = model.predict(X)[0]
    prob = model.predict_proba(X)[0]

    signal = 'BUY' if pred == 1 else 'SELL'
    confidence = prob.max()

    print(f'  Signal {i+1}: {signal} (confidence: {confidence:.2%})')

print('✅ Integration test complete')
"
```

**Expected Results:**
- 10 signals generated without errors
- Confidence scores in range [50% - 100%]
- Execution time: <1 second for 10 signals
