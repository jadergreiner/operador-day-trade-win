## 2️⃣ Manual Override Testing

### Override Levels (3 tiers)
```
TIER 1: Trader Manual Veto
  - Trader can STOP any trading signal
  - Trader can CANCEL any pending order
  - Interface: Dashboard "VETO" button
  - Latency: <100ms to take effect
  
TIER 2: CIO Pause Program
  - Pause ALL automatic signals
  - Resume when ready
  - Interface: "PAUSE/RESUME" button
  - Scope: Program-wide

TIER 3: CFO Capital Halt
  - Stop using capital from account
  - Only manual trades allowed
  - Interface: Set risk limit to 0
  - Purpose: Emergency circuit breaker
```

### Test Cases

**Test Case 1: Trader Veto Single Order**
```
1. Wait for BUY signal generation
2. Click "VETO" button on signal
3. Verify order NOT sent to MT5
4. Confirm signal marked "VETOED" in log
5. Expected: <100ms latency
Status: [ ] PASS [ ] FAIL
```

**Test Case 2: CIO Pause Program**
```
1. Click "PAUSE SIGNALS" button
2. Wait for 5 new signals (should generate)
3. Verify NONE are sent to MT5
4. Resume program
5. Next signal should execute normally
Status: [ ] PASS [ ] FAIL
```

**Test Case 3: Manual Trade While Program Paused**
```
1. Pause automatic program
2. Open MT5 terminal
3. Manually send BUY order
4. Verify order executes

Status: [ ] PASS [ ] FAIL
```

## 4️⃣ Team Training Session (30 min)

### Audience
- Trader (Primary)
- CIO (Secondary)
- CFO/Finance (Optional)
- On-call Support (Optional)

### Training Agenda

**Segment 1: Overview (5 min)**
```
What is the system?
  - Automated trading with ML confidence scoring
  - Phase 1 Beta: 62% win rate (validated)
  - R$ 50k capital (approved)

Why are we doing this?
  - Monetize market opportunities 24/5
  - Remove emotion from trading
  - Scale consistent profitability

What does it do?
  - Detects 85%+ of profitable opportunities
  - Sends signals with 50-90% confidence
  - Executes orders with 3-layer risk gating
```

**Segment 2: Dashboard Tour (5 min)**
```
Left Panel:
  - Confidence Scores (current ML confidence)
  - Win Rate (backtested vs live)
  - P&L (today, this week, lifetime)

Center Panel:
  - Signal Generation (BUY/SELL signals with confidence)
  - Recent Trades (list of last 10 orders)
  - Performance Chart (equity curve)

Right Panel:
  - Position Monitor (current open positions)
  - Risk Metrics (drawdown, sharpe ratio)
  - Circuit Breaker Status (green/yellow/red)
```

**Segment 3: Manual Override Demo (5 min)**
```
Demo 1: Veto a trade
  Step: Click VETO button on next signal
  Result: Trade blocked, logged in audit trail
  
Demo 2: Pause program
  Step: Click PAUSE SIGNALS
  Result: New signals don't execute
  
Demo 3: Resume program
  Step: Click RESUME
  Result: Next signal executes normally
```

**Segment 4: Emergency Procedures (10 min)**
```
If something looks wrong:
  1. Contact: CIO (first) → CFO (escalate if needed)
  2. Actions: Review capital usage, recent trades, P&L
  3. Decision: Continue, Pause, or Halt program
  
If capital hits -3%:
  - System sends ALERT
  - Trader can pause
  - Review strategy
  
If capital hits -5%:
  - System enters SLOW MODE
  - 50% ticket size only
  - 90% + confidence required
  
If capital hits -8%:
  - System HALTS
  - No automatic trades
  - Manual-only mode
```

**Segment 5: Daily Procedures (5 min)**
```
Morning (09:00 BRT):
  [ ] Check overnight P&L
  [ ] Review any paused signals
  [ ] Verify system health

Afternoon (14:00 BRT):
  [ ] Check daily P&L
  [ ] Review confidence scores
  [ ] Check circuit breaker status

Evening (17:00 BRT):
  [ ] Check position history
  [ ] Review any unusual trades
  [ ] Close daily recap

Weekly (Monday):
  [ ] Review win rate (target: 60-62%)
  [ ] Check correlation patterns
  [ ] Validate feature performance
```

### Q&A Session
```
Q: What if I don't trust the signal?
A: Use VETO to block trade, no penalty. System learns from your input.

Q: What's the maximum drawdown allowed?
A: Circuit breakers kick in at -3% (alert), -5% (slow mode), -8% (halt)

Q: Can I manually trade while system is on?
A: Yes. Your manual trades update the position monitor. Be aware of total exposure.

Q: What if the model is wrong?
A: 62% win rate means ~38% will lose. This is NORMAL. Over 100 trades, profit.

Q: How often are signals generated?
A: Depends on market opportunity. On WINFUT: 2-5 signals per day. Variable.
```
