5️⃣ SE ALGO DER ERRADO
═══════════════════════════════════════════════════════════════════════════════

CENÁRIO A: Penalties não aparecem
────────────────────────────────
  Problema: P0 não está penalizando inatividade
  Causas: Agent crashed, modelo descarregou, inatividade < 120 min
  Solução:
    1. Verificar: Get-Process python
    2. Se não rodando: INICIAR_MICRO_TENDENCIA_AUTO_TRADE.bat
    3. Se rodando: Select-String "PENALTY" outputs/agent_execution.log
    4. Aguardar 30 min, testar novamente


CENÁRIO B: Erros encontrados
────────────────────────────
  Problema: agent_execution.log mostra erros
  Causas: Modelo carregamento falhou, MT5 desconectou, SQL error
  Solução:
    1. Ver erro: Select-String "ERROR\|ERRO\|Exception" outputs/agent_execution.log
    2. Se SQL error: rollback database:
       Copy-Item data/db/trading.db.backup_06mar.bkp data/db/trading.db
    3. Relançar: INICIAR_MICRO_TENDENCIA_AUTO_TRADE.bat
    4. Check novamente em 1 hora


CENÁRIO C: Confidence continua caindo
─────────────────────────────────────
  Problema: Conf 0.46 → 0.45 (piorando)
  Causas: Pode ser normal nos primeiros 2 dias, ou indicador real de problema
  Solução:
    1. Dias 1-2: Esperar (confidence pode ter lag)
    2. Dia 3+: Se continua: problema real
       a. Ver: Select-String "confidence\|CONFIDENCE" outputs/agent_execution.log
       b. Se logs ok mas confidence cai: modelo precisa treinar mais
       c. Opção: Deixar rodar mais 2 dias ou debug profundo


CENÁRIO D: Trades = 0 mesmo com penalties
──────────────────────────────────────────
  Problema: Penalties aplicadas mas modelo não entra em trades
  Causas: Threshold MT5 muito agressivo, ou BDI não validando, ou SMC não alinhado
  Solução:
    1. Verificar: Select-String "TRADE\|ORDEM" outputs/agent_execution.log
    2. Ver se há "opportunity rejected": motivo é qual?
    3. Se BDI: verificar dados históricos (BDI detection pode estar broken)
    4. Se SMC: verificar níveis SUPPORT/RESISTANCE (pode estar errado)
    5. Debug específico em cada módulo
