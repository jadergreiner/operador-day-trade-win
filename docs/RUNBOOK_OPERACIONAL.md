# Runbook Operacional

Este documento lista os procedimentos operacionais para o projeto Operador Day Trade Win.

## Procedimentos Operacionais

1. **Preparação do Ambiente**
   - Verifique se todas as dependências estão instaladas.
   - Configure suas credenciais da API.
   
2. **Execução do Programa**
   - Execute o programa usando o comando `python main.py`.
   
3. **Monitoramento de Erros**
   - Verifique os logs localizados em `logs/error.log` para qualquer erro durante a execução.
   
4. **Interrupção Segura**
   - Para interromper o programa, use `Ctrl + C` e verifique se todas as operações em andamento foram finalizadas.
